Google Play Store Analysis

Project Overview

This project performs an exploratory data analysis of the Google Play Store ecosystem using app information and user reviews.

The analysis focuses on understanding app categories, ratings, app size, installs, pricing, estimated revenue, and user sentiment. The project also provides interactive visualization to make category-level insights easier to explore.

Objective

The main objectives of this project are:

- Clean and prepare Google Play Store app and review datasets.
- Analyse app distribution across different categories.
- Study app rating patterns and average ratings by category.
- Analyse the relationship between app size and number of installs.
- Compare free and paid applications.
- Analyse the pricing distribution of paid applications.
- Estimate revenue generated by paid apps across categories.
- Perform sentiment analysis on user reviews using VADER.
- Analyse positive and negative sentiment across app categories.
- Create interactive visualizations for better data exploration.

Datasets

The project uses two datasets:

1. Google Play Store Apps Dataset

2. Google Play Store User Reviews Dataset

Project Workflow

1. Data Loading

The Google Play Store apps dataset and user reviews dataset are loaded separately using Pandas.

2. Data Cleaning

The following preprocessing steps were performed:

- Checked missing values.
- Filled missing ratings using the median.
- Filled missing app type values using the mode.
- Removed reviews with missing review text.
- Removed malformed category records.
- Converted "Installs" into numeric format.
- Converted "Price" into numeric format.
- Checked and removed duplicate records.
- Verified final data types and dataset shapes.

3. Category Analysis

The number of applications in each category was analysed to identify highly competitive and saturated categories.

Key finding:
The FAMILY category contains the highest number of apps with 1,943 apps, followed by categories such as GAME and TOOLS.

4. Ratings Analysis

The project analyses:

- Distribution of app ratings.
- Average rating for each app category.
- Category-wise rating comparison using visualizations.

5. App Size and Installs Analysis

App sizes were converted into MB and compared with the number of installs.

A scatter plot was used to visualize the relationship.

Key finding:
The correlation between app size and installs is approximately 0.169, indicating a weak positive relationship. Therefore, app size alone is not a strong predictor of app popularity.

6. Pricing Analysis

The project analyses:

- Free vs paid applications.
- Distribution of paid app prices.
- Price statistics for paid applications.
- Estimated revenue by category.

Estimated revenue was calculated using:

"Estimated Revenue = Price × Installs"

Since the dataset provides install ranges rather than exact install counts, the calculated revenue represents an estimate.

7. Sentiment Analysis

VADER sentiment analysis was applied to user reviews.

Reviews were classified into:

- Positive
- Negative
- Neutral

The overall sentiment distribution was analysed to understand user opinions about applications.

8. Sentiment by Category

User reviews were connected with app categories and analysed to identify:

- Categories with the highest positive sentiment.
- Categories with the highest negative sentiment.
- Category-wise sentiment distribution.

A comparison chart was created for positive and negative reviews across categories.

9. Interactive Visualization

Plotly was used to create an interactive visualization showing the distribution of applications across categories.

The interactive chart allows users to explore category-level app counts through hover-based interaction.

Key Insights
- FAMILY is the most saturated category with 1,943 apps.
- The relationship between app size and installs is weak, with a correlation of approximately 0.169.
- Free applications significantly outnumber paid applications.
- Paid app prices are generally concentrated at relatively lower values, with fewer high-priced applications.
- Estimated revenue differs considerably across app categories.
- User sentiment varies across categories, providing useful information about user satisfaction and potential areas for improvement.

Recommendations

Based on the analysis:

- Developers can consider less saturated categories to reduce competition.
- App quality and user experience should be prioritised instead of relying primarily on app size.
- Pricing patterns can be considered when developing monetization strategies.
- User reviews and sentiment should be monitored to identify customer concerns.
- Category-level sentiment can help developers understand user expectations and improve applications.

Conclusion

This project provides a comprehensive analysis of the Google Play Store using application data and user reviews. The analysis covers category competition, ratings, app size, installs, pricing, estimated revenue, and sentiment.

The findings demonstrate how exploratory data analysis and sentiment analysis can be used to understand application performance, user satisfaction, competition, and monetization opportunities in the Google Play Store ecosystem.
